# 400문항씩 비교하는 장기 실험 — 서버 재부팅으로 중단

2026-09-09 서버 재부팅 이후 기존 서비스와 프로세스가 없음을 확인했다.
요청 파일을 검증한 결과 **8,100행**, 완료된400문항 trial20회와 다음 trial100행이다.
첫 반복18조건 전체는 완료됐지만 전체3반복은 완료되지 않았다.
원본 상태 파일의 `latency_running`과 기존 로컬 snapshot은 중단 전 마지막 기록으로,
현재 실행 상태를 나타내지 않는다. 원본과 실패/부분 자료는 덮어쓰지 않았다.
사용자 요청으로 이후 실험은 별도 [300문항 재개분](../workflow300-20260909/README.md)에서
실행하며 두 시대의 결과를 단순 합산하지 않는다.

각 조건에 동일한 고유 질문 400개를 사용한다. A/B/C × 사용자 1/2/4/8/16/32 × 3반복,
총 21,600회 계획이며 전체 완료 결과는 아직 없다.
[고정 프로토콜](../../../docs/WORKFLOW400_PROTOCOL_20260908.md).

- `frozen-plan.json`: 질문·코드·설정 해시, 실행 순서, 규모. 독립 holdout 아님.
- `data-health-preflight.json`: 검색 인덱스 문서 수와 DB read-only 연결 확인.
- `preflight.json`: 모델 health/tokenizer/cache/source 사전 관측.
- `status-snapshot.json`: 명시된 시각의 상태 복사본. 이 로컬 파일은 자동 갱신되지 않는다.

아래는 중단 전 계획과 사전 관측이다. 원문/인증은 공개 폴더에 넣지 않는다.
지연 측정 종료 후 자동 분석 및 각 부하 첫 반복의 출처 QA131×3조건 평가를 계획했으나
전체 지연 실험 이전에 중단되어 해당 후처리는 완료되지 않았다.
전문가 정확도/안전 평가가 없어 운영 release는 계속 금지한다.

초기 구성 오류 실행은 151개 완료 행 이후 중단됐고, 그 결과는 새 비교에 합산하지 않는다.
정상 구성의 새 실행은 2026-09-08 22:49:49 KST에 시작했다. 초기 모델 health 검사만으로
검색 설정 누락을 잡지 못해, 유효 dotenv 설정과 검색/DB 직접 검사를 추가했다.
이전 64문항의 정책 실패 실험과 초기 구성 오류 실행 모두 원자료를 별도로 보존한다.
