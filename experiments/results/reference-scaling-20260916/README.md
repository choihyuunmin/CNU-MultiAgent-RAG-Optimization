# 참조 ID 축약·복원: 동시 요청 1~200 실측 자료

2026-09-16 KST, 실제 검색기 소스와 공유 GPU 모델 서버로 측정했다.
**1·2·4·8·16·20·32·50·100·150·200의 11개 지점**, 두 조건·두 반복,
총 **2,896요청**이다. 정상 완료 2,741건, 시간 초과 155건을 모두 포함한다.
기존 조건은 1,448건 중 1,318건, 개선 조건은 1,448건 중 1,423건 정상 완료했다.

개선 조건은 **낮은 worker reasoning + 참조 ID 축약·복원**이다. 후보가 16개 이상이면
긴 문서 ID를 짧은 번호로 전달하고, 선택 결과에서 실제 ID로 복원한다.
본문·제목·검색 점수는 줄이지 않는다. ID 기능만의 기여는 이전 3조건 실험과 구분한다.

## 주요 결과

| 동시 요청 | 평균 관측시간 기존→개선 | 정상 완료율 기존→개선 |
|---:|---:|---:|
| 100 | 96.64→84.74초 | 100%→100% |
| 150 | 148.37→132.63초 | 79%→100% |
| 200 | 153.16→150.65초 | 83.25%→93.75% |

시간 초과는 240초에서 관측을 끝낸 것이므로 실제 완료 시간이 아니다.
200개 구간의 단축률 95% 구간은 −1.41~4.57%, p95는 두 조건 모두 240초다.
법령 재현율 79.25%, 자동 평가의 큰 반복 변동도 있어 **200개 구간의 안정적인
속도·품질 개선을 입증하지 못했다.** 전문가 정확도 유지도 미입증이다.

## 측정 범위

- 같은 부하에서는 같은 질문으로 비교했다. 질문 수/회는 `max(32, 동시 요청 수)`다.
- 32개 이상은 한 번에 제출한 유한 요청 묶음이다. 지속적인 동시 사용자 용량이 아니다.
- 부하별 질문 수가 달라 곡선에는 질문 구성의 영향도 있다. 개선율은 각 부하 안에서 비교한다.
- 기존 200문항 회귀셋을 재사용했다. 새로운 미관측 벤치마크가 아니다.
- 검색 도구·설정은 고정했지만 모델의 검색 인자와 반환 후보는 실행마다 달라질 수 있다.
- 자동 평가는 첫 반복의 사전 지정 236건과 사후 추가한 200개 두 번째 반복 130건이다.
  366건 모두 판정 완료, 판정 오류와 근거 잘림은 0건이다. 전문가 평가를 대체하지 않는다.
- 비공개 질문·답변 원문, 운영 환경 파일, 인증 값은 포함하지 않는다.

동결된 실행 코드는 원격 실험 내내 같았다. 공개 저장소와 비교하면 149개 중 148개가
같으며, 유일한 차이는 이전 합성 실험 그림 스크립트 `scripts/plot_reference_topologies.py`의
범례를 구체적인 기능명으로 바꾼 한 줄이다. 이 스크립트는 이번 성능 측정에 실행되지 않았다.
새 보고서·그림·추가 판정 도구는 측정 이후의 후처리 코드다. 동결 해시를 덮어쓰지 않았다.
