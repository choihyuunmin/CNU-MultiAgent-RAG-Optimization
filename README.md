# Multi-Agent RAG Optimization

멀티에이전트 RAG(검색 증강 생성) 시스템의 응답 지연을 줄이기 위한 Python 최적화 모듈과 실험 도구를 개발하는 프로젝트입니다. 에이전트의 실행 흐름, 모델 호출, 네트워크 통신에서 발생하는 병목을 분석하고 개선 방법을 검증합니다.

## 주요 기능

- **실행 경로 선택**: 입력 조건과 검색 근거를 검사해 실행 경로를 선택하고, 조건이 충족되지 않으면 기존 모델 처리로 돌아갑니다.
- **도구 호출 검증**: 선택된 검색 도구에 전달할 인자의 형식과 값을 검사합니다.
- **통신 연결 재사용**: 모델·임베딩·재정렬 요청에 HTTP 연결 풀을 사용합니다.
- **병렬 실행과 선실행 검증**: 독립적인 작업을 병렬로 처리하고, 미리 실행한 결과는 확정된 검색 근거와 일치하는지 확인한 뒤 사용합니다.
- **실행 계측과 품질 평가**: 모델 호출 시간을 기록하고, 같은 질문에 대한 검색 문서·순위·응답의 일치도를 비교합니다.

## 적용 방식

공통 모듈은 Python 매핑과 데이터 클래스를 사용하며, 특정 검색 서비스나 도메인에 의존하지 않도록 구성합니다. 적용하는 시스템에서 검색 도구, 모델 호출 함수와 품질 평가 기준을 연결합니다. 실제 성능과 답변 품질은 각 시스템에서 검증해야 합니다.

## 저장소 구성

- `src/cnu_rag_optimization/`: 최적화 및 평가 모듈
- `examples/`: 연동 예제
- `integrations/`: 개별 검색 시스템 연동 코드
- `scripts/`: 실험 실행과 결과 분석 도구
- `tests/`: 기능 검증 테스트
- `docs/`: 설계와 실험 방법 문서
- `experiments/`: 실험 설정과 결과 자료
