# 연구 피드백 회신 초안

말씀 주신 대로 논문에 사용자 규모 증가에 따른 종단 성능 저하와 원인 분석을 추가하고,
실제 서버에서 규모별 실험을 진행했습니다. 먼저 기존 2.9%는 16명이 아니라 동시성 4의
전체 응답시간 단축률이며, 신뢰구간이 0을 포함해 유의한 개선을 확인한 결과는 아닙니다.

64개 고정 질문을 사용자 1·2·4·8·16·32명에서 실행한 결과, 평균 관측 지연은
각각 13.86·15.02·18.31·29.60·59.78·108.08초였습니다. 첫 스윕 384회 중 383회가
정상 완료했고, 32명에서 180초 기한 초과가 발생해 계획한 두 번째 반복은 중단했습니다.
성공 요청만 골라 지연을 계산하지 않았으며, 단발 진단 결과로 명시했습니다.

이후 서버 접속을 확보해 현재 pod의 소스·설정을 직접 확인했습니다. 생성 실행 상한 4
외에 SSE 전송이 끝날 때까지 유지되는 HTTP 상한 4가 중첩되어 있었습니다.
내부 생성 큐의 대기가 0이어도 HTTP 앞단에는 대기가 생길 수 있는 구조입니다.
초기 1→16명 지연 증가의 약 94%가 첫 진행 이벤트 이전에 나타났던 관측과 연결됩니다.

또한 약 1만 7천 자의 비교 답변은 첫 답변 이후 전송에 약 68초가 걸렸습니다.
이는 보관된 코드의 5자/20ms 전송 대기와 가깝고, 같은 함수의 합성 완성 텍스트
CPU 재현에서도 확인했습니다. CPU 재현은 실제 GPU API의 가속 검증과 구분했습니다.

단순 외부 동시성 제한의 192회 대조는 총 지연 단축이 1.88%·0.67%에 그쳐 채택하지
않았습니다. 이어 별도 앱에서 두 상한과 전송 방식의 다섯 조건을 비교한 320회는 모두
완료했습니다. 전송 대기만 제거한 조건은 평균 개선이 없었고, 두 상한을 함께 조정했을 때
개선이 나타났습니다. 상한 16·즉시 전송을 후보로 고정했습니다.

같은 64문항을 사용자 16·32명에서 기준/개선 각 2회씩, 순서를 교차한 새 검증
**512회도 모두 정상 완료**했습니다. 최종 평균은 다음과 같습니다.

| 사용자 상한 | 기준 | 개선 | 평균 단축 | 질문 단위 95% CI |
|---:|---:|---:|---:|---:|
| 16 | 60.36초 | 34.04초 | 43.60% | 38.84~48.55% |
| 32 | 104.16초 | 52.61초 | 49.49% | 46.55~52.34% |

같은 조건의 p95도 16명 78.28→56.58초, 32명 146.88→78.59초로 감소했습니다.
출처 법령·조문 포함은 같았지만 답변 문자열 동일성이나 전문가 품질 동등성까지
입증한 것은 아닙니다. 32명 개선 조건에서도 30초 이내 완료는 8.59%여서 서비스 SLO
달성과 상대 개선을 구분했습니다. 후보 선택용 실행과 새 검증은 합산하지 않았습니다.

메모리도 직접 계측했습니다. 가용 host RAM은 460GiB 이상이고 swap·OOM 증가는
없었습니다. Nsight DRAM 활동에서 지속 포화는 관측하지 못했지만, 선택용 상한 16은
KV 최대 99.73%까지 사용했습니다. 반복 검증은 KV 최대 98.93%, 선점 0이었습니다.
또한 GPU 0 전력 제한에 따른 클록 감소 누적이 진행 중·종료 관측 사이 약 260초
증가했으므로, GPU 자원 경합이 없다고 결론 내리지는 않았습니다.

기술적 후속 방향은 장문 선별의 캐시에 없는 입력 토큰·KV 블록 수요에 따른 단계별
수용 제어와, 혼잡 시 추측 실행을 줄이는 정책입니다. 짧은 분류와 긴 문서 선별을
구분하되 긴 요청의 기아를 방지하고, 모델 실행과 HTTP 전송의 자원 수명도 분리해야 합니다.
이는 후속 대조가 필요한 제안이며 이번 43.60%·49.49%를 해당 알고리즘의 성능으로
주장하지 않습니다. 기존 2.9%와도 다른 조건의 결과이므로 단순 개선 전후 비교하지 않습니다.

선택용·반복 검증 주 대조 832회, 예비·제외 기록, GPU 관측과 한계를
[후속 결과 보고서](MOLEG_SCALING_ISOLATED_RESULTS_20260907.md)와
[보완 논문](MOLEG_PAPER_DRAFT_20260905.md)에 반영했습니다.
운영 vLLM·K8s는 변경하지 않았고 실험 앱·계측 종료와 임시 인증 사본 삭제도 마쳤습니다.
전문가 답변 평가, 실제 사용자 질의의 대표성, 장시간 안정성, 제출처 양식 확정은 남아 있습니다.

이 문서는 회신용 초안이며 실제 메일·메신저로 발송하지 않았다.
