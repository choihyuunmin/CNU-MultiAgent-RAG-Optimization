# 인스턴스 효과 후속 실험 결과 (2026-09-18)

집계: `experiments/results/dispatch-instance-followup-20260918/` · 논문 초안 6.3절 · 배경: `experiments/results/dispatch-review-20260916/self_repeat.json`

## 질문

09-16 3라운드 실험에서 arm 간 법령 집합 일치율(89–92%)이 각 arm의 라운드 간 자기 일치율(95%)보다 낮았고, 같은 메커니즘인
미서명·서명 사이도 91%였다. arm마다 파드가 하나였으므로 arm 효과와 인스턴스 효과를 분리할 수 없었다. 같은 arm을 파드 두 개로
돌려 "같은 arm·다른 인스턴스"의 일치율을 재고, 핸들러 출력 해시로 검색 결과의 동일성을 직접 확인했다.

  대비되므로 인스턴스 내부 캐시 등 인스턴스 상태가 결과를 고정하는 것으로 보인다.

- 조건: 오케스트레이터 엔진의 완료되지 않은 요청 1건이 실험 내내 남아 있었다(유휴 게이트 "실행 ≤1"). 프로덕션이 엔진을 공유했다.

## 함의

직접 디스패치의 품질 영향은 이 시스템의 검색 비결정성 안에 있다. 디스패치 방식의 품질 비교는 arm당 여러 인스턴스를 쓰거나
검색 경로를 결정적으로 고정한 뒤에 해야 한다.
